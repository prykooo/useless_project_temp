### Project Description

**Who Pays** is a fun group game that turns the simple question “Who pays the bill?” into an entertaining mini-game. Players enter their names and bill amount, receive mystery cards, and spin a roulette to determine the final payer.

### The Problem (that doesn't exist)

Every time a group finishes eating, there is one extremely serious question:

**“Who is going to pay the bill?”**

Instead of simply deciding, we created a completely unnecessary system to make this tiny problem much more dramatic. 😌

### The Solution (that nobody asked for)

**Who Pays** uses a roulette wheel and mystery cards to decide who pays the bill.

Players can receive **SAFE, LUCKY, SWAP, or DOUBLE** cards, each affecting the final result. After the decision, the game reveals the payer with a funny Malayalam-style dialogue, while player statistics are updated for the leaderboard and character profiles.
